Alternative iOS setup · iOS 16+

Get ready for Cinemana with LiveContainer.

For people who prefer free sideloading, use the official LiveContainer + SideStore package. Set it up once, then import compatible IPA files inside LiveContainer.

Important: LiveContainer is not an App Store installer. iOS still requires a valid signing setup for LiveContainer itself. The first installation generally needs a computer, and free Apple provisioning may require refreshes. There is currently no public Cinemana IPA install link on this site.
Official LiveContainer + SideStore guide ↗ Official LiveContainer GitHub ↗

1. Install LiveContainer + SideStore

  1. Prepare a Windows PC or Mac

    For Windows, install Apple device drivers through iTunes, then connect the iPhone and trust the computer.

  2. Download the official LiveContainer + SideStore IPA

    Use the download links on the official installation guide, not third-party modified or closed-source builds.

  3. Install with Impactor or iloader

    Follow the official guide exactly. These tools handle the initial signing with your Apple account. Keep the required app extensions and verify the developer profile in iOS settings.

  4. Complete built-in SideStore setup

    Open SideStore from LiveContainer, sign in through its supported workflow, connect LocalDevVPN, and refresh the installed app.

  5. Enable JIT-less app launching

    Open LiveContainer Settings → Import Certificate from SideStore, then run JIT-Less Mode Diagnose until it passes.

Already installed LiveContainer? Skip to step 2. Official installers and supported iOS versions can change; follow their current documentation rather than outdated video tutorials.

2. Install compatible IPA files

  1. Download a trustworthy IPA from its authorized developer

    Download it in Safari or Files. Do not install unknown, re-signed, or modified Cinemana builds.

  2. Open LiveContainer → Apps → +

    Select the IPA from Files and let LiveContainer import it, then choose it for the next launch.

  3. Add it to your Home Screen (optional)

    Use LiveContainer's Launch App Shortcut guide to create a convenient Home Screen icon.

Frequently asked questions

Can I install LiveContainer with one tap from Safari?

Not on an ordinary iPhone without a previously established signing/distribution method. LiveContainer must be installed through a supported signing tool first.

Can I use Sideloadly for LiveContainer?

The official LiveContainer guide currently lists Sideloadly, 3uTools and most online signers as unsupported. Use the recommended Impactor/iloader workflow.

Is this the same as the App Store version?

No. LiveContainer runs compatible iOS guests within its own app. Guest entitlements, background tasks, app extensions and system integrations may behave differently, so compatibility is not guaranteed.

Do I need to enter my Apple ID on the Cinemana website?

No. Never enter Apple credentials into a Cinemana page, a random certificate-selling service or an unofficial LiveContainer build. Any required signing/login is performed in the official tool's own setup.
