Install Cinemana Web

  1. Open this page in Safari on your iPhone.
  2. Tap Share, then Add to Home Screen.
  3. Enable Open as Web App and tap Add.

The icon will open Cinemana Web without Safari's tabs. No Apple ID sign-in is needed.

The web app can't bypass provider network restrictions or Safari's media permissions.

Play a media URL

Paste an HTTPS MP4 or HLS link you have permission to play. This does not bypass DRM or provider restrictions.
