# Cinemana CEE Android TV (experimental)
Independent package `app.cinemana.cee.tv` on isolated GitHub branch `cee-ios-v0.1.0`. The app uses a live CEE webpage, a native discovered-poster grid, saved links, search, bilingual controls and website fullscreen video. It does **not** claim an authenticated CEE stream API, native episode catalog, adaptive-quality enforcement, or automatic skip-marker accuracy.
The APK built by GitHub Actions is **debug/test-signed**, not a production signed release. Installed package can coexist with CinemanaTV.
